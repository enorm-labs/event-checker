Everything under Environments sits behind the WireGuard tunnel and a port-forward. One command opens both, one closes them. Run either from the repository root; up asks for your password once, for wg-quick.

A green dot means the local port answers right now, probed by this page. A port-forward accepts the connection before the pod does, so green proves the forward, not the service; the Swagger link is the proof of the service.
